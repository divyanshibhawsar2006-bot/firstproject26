IMovies – Movie Ticket Booking Website

IMovies is a full-stack movie ticket booking web application built with the MERN stack (MongoDB, Express.js, React.js, Node.js). Users can browse movies, choose a theatre, show and seats, pay securely online and receive an e-ticket with a QR code instantly. An admin panel lets theatres manage movies, shows, prices and offers.

Problem Statement

Booking movie tickets is often slow and unreliable: long queues at box offices, showtimes scattered across different places, uncertainty about seat availability, insecure payments and delayed refunds. IMovies solves this with a single, easy-to-use booking platform.

Features-
For Users:
1.Register, log in and reset or change password securely.
2.Browse Now Showing and Upcoming movies with details and ratings.
3.Search and filter movies by title, language, genre and rating.
4.Select theatre, date and showtime.
5.Interactive seat map with real-time availability and temporary seat hold.
6.Apply coupons and pay online (UPI, cards, net banking).
7.Instant e-ticket with QR code via email/SMS.
8.View booking history, cancel bookings and get refunds.
9.Rate and review movies after booking.

For Admin:
1.Add, edit and delete movies, theatres and shows.
2.Set ticket prices and manage coupons and offers.
3.View booking and sales reports.

Tech Stack

Frontend--React.js, HTML, CSS, JavaScript, Bootstrap / Tailwind CSS
Backend--Node.js, Express.js (REST APIs)
Database--MongoDB with Mongoose
Authentication--JWT, bcrypt
Payments--Razorpay API
Notifications--Nodemailer (email), SMS service
Hosting--Vercel / Render, MongoDB Atlas
